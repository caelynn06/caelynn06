## 👋 About me

I'm a junior at **UTEP** studying **Computer Science** with a data analytics concentration and an **Electrical Engineering** minor. I started out in animation and architecture at El Paso Community College, then moved into CS because I wanted to keep the creative side of design but point it at harder problems.

What got me hooked on the space industry was standing near a rocket hotfire test during my first internship. I haven't really recovered since.

My north star is **embedded software combined with computer vision and ML**, the kind of code that runs close to the hardware and has to be right.

## 🛰️ What I've been building

| Where | What I do |
| --- | --- |
| 🚀 **Blue Origin** | Data science and ML on supply chain software, data pipelines, and part data analysis |
| 🔥 **Sierra Lobo (NASA test facility)** | Full stack database system that supports rocket testing operations |
| 🤖 **UTEP Robotics and Automation Society** | ROS 2 and C++ on a UAV and UGV system as part of the Electrical and Software team |
| 🧠 **Undergraduate research** | Applying machine learning to medical decision making |
